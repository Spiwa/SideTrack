SideTrack

A compact player for JRiver · Offline help

Connect to JRiver

  1. Open JRiver Media Center and enable its Media Network / MCWS server.
  2. Right-click SideTrack and choose Settings, or press F2 while the player has focus.
  3. On the JRiver tab, enter the server address, port, username and password. Use localhost when JRiver runs on the same computer. Enter the actual server port configured in JRiver; the initial value is 52199.
  4. Select Test connection, then Save and restart.

The connection test is read-only. A successful connection does not require a track to be playing. Saved passwords are encrypted for your Windows user account.

Use the player

Hover over a button for its name. Previous track, Play/Pause, Stop, Next track and Artist Radio are available below the waveform. The small controls at the top-right minimize and close the player.

Drag the artwork, text or empty panel to move SideTrack. Position is saved automatically. Right-click for Settings and Help. Press F1 for this built-in guide.

Player settings

  • Size: Small, Normal or Large. Size takes effect after restart.
  • Always on top: keep SideTrack above other windows. This takes effect when saved.
  • Start with Windows: start the player when your Windows user signs in. No administrator access is needed.

Save keeps the player running; connection, size and integration changes apply on the next launch. Save and restart applies all changes immediately.

Artwork, colors and waveforms

Artwork comes from JRiver. The theme uses a representative cover color and a diagonal gradient; hover over the artwork to see the extracted color and its hex code. Color saving is optional and off by default for new users. Under Settings → Library & snapshots, enable Save artwork primary color to JRiver and enter an existing custom text field. The default name is album art primary color. Use Check field to verify it. SideTrack never creates fields automatically and will not write to built-in or non-text fields. Your current personal setup may have this option enabled to preserve earlier behavior.

The waveform uses the track's existing waveform metadata field, containing semicolon-separated amplitude samples. SideTrack does not analyze audio files to generate this data. If it is absent, a plain progress bar appears instead. Both displays are read-only and show elapsed time on the left and duration on the right. A fixed visual bar width and gap are used for waveforms; the source samples are resampled to that grid, so different track durations and sample counts do not crowd the bars.

Save player snapshots

Right-click the player and choose Save snapshot…. Choose a filename and location to save a PNG containing the artwork, track details, waveform and controls. The desktop, menus, tooltips and external shadow are excluded; snapshots are rectangular with square corners.

Under Settings → Library & snapshots, set an optional default folder or disable the snapshot command. You still choose the destination for each manual snapshot. Automatic snapshots are off by default. To enable them, choose an existing folder and select Save a snapshot when a new track starts. One PNG is saved per track start, without a file dialog; pausing and resuming does not create duplicates. Automatic snapshots omit elapsed time and played-progress highlighting, while keeping total duration. Manual snapshots retain elapsed time and progress. Filenames include the artist, title and timestamp. Snapshot and color-saving preferences apply when saved, without restarting.

Optional integrations

Artist Radio: enable this only if you have Perl, MCUtils and the JRiver fields smartlistartistquery and smartlistartistpath set up. Select the MCUtils folder containing pscriptor.pl. When enabled, the existing automatic scheduling after playback stops is preserved. Clicking during playback queues the action until playback stops.

TrackInfo Last.fm helper: select your existing helper Python script. SideTrack starts it with --server and stops the process it started when the player closes. It supplies data for your TrackInfo pages; it is not a scrobbler in SideTrack. This optional integration requires a separate working Python installation and the helper's dependencies. Select its Python executable in Integrations if SideTrack cannot detect it. The core player does not require Python.

Troubleshooting

  • Cannot connect: confirm JRiver is running, Media Network is enabled, and the port and credentials match. For a different computer, check its address and firewall settings.
  • No waveform: confirm the playing track has the waveform custom field. A normal progress bar is expected when it does not.
  • Artist Radio unavailable: verify the integration is enabled, the MCUtils folder is correct and Perl is installed.
  • Changes not visible: use Save and restart. Existing running instances retain their connection and size until restarted.

Settings and logs

SideTrack stores personal settings and sidetrack.log in %APPDATA%\SideTrack, separate from its program files. Do not share your settings file: it contains your server details and encrypted credentials.

To reset preferences, close SideTrack and rename settings.json in that folder. The setup screen will appear next time. If Start with Windows was enabled, turn it off in Settings before resetting preferences.
